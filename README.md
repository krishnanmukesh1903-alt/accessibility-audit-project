# Component architecture

Reusable semantic patterns used in the dashboard:
- Site header and primary navigation (`header`, `nav`).
- Workspace sidebar (`aside`, labelled navigation).
- KPI cards (`article`).
- Main content panels (`section`) and complementary quick actions (`aside`).
- Accessible data tables (`table`, `caption`, scoped row/column headers).
- Form controls grouped with `fieldset` and `legend`, explicit labels and native validation.
- Native modal dialog (`dialog`) with a labelled heading and keyboard-operable controls.

Shared styles are in `css/styles.css`; shared interactions are in `js/app.js`.
