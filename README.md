# Accessibility Audit Project

## 1. Project Overview

This project focuses on building an accessible and maintainable full-stack web application.

The project includes an accessibility audit of Amazon India using Google Lighthouse and keyboard navigation testing.

## 2. Project Structure

```text
accessibility-audit-project/
├── client/
├── server/
├── docs/
├── tests/
└── README.md
```

## 3. Architecture

- **Client:** Handles the user interface and frontend components.
- **Server:** Handles backend logic and API requests.
- **Docs:** Stores project documentation and accessibility audit reports.
- **Tests:** Stores test cases and accessibility testing files.

## 6. First Feature Slice

The first feature is an Accessibility Audit module.

It will:
- Identify accessibility issues.
- Record audit evidence.
- Display issue severity.
- Suggest recommended fixes.

## 7. Accessibility Audit

Website audited: Amazon India

Lighthouse Accessibility Score: 89/100

The audit identified issues related to:
- ARIA attributes.
- Link accessible names.
- Redundant image alternative text.
- Touch target size and spacing.
- Heading order.
